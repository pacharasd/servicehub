# คู่มือการใช้งานและการอ่านรายงาน ServiceHub

เอกสารฉบับนี้อธิบายแนวทางและหลักการจัดทำรายงานสำหรับติดตามงานบริหารของ ServiceHub ทั้งในรูปแบบหน้าจอเว็บ (Web Interface) และไฟล์ส่งออก (CSV Export)

---

## 1. การเข้าถึงรายงานและสิทธิ์การใช้งาน

- **รายงานภาพรวม (`#/reports`):** แสดงสรุปผลการดำเนินงานทุกหมวดที่ผู้ใช้มีสิทธิ์เข้าถึง (`{module}.view`) แบ่งตาม 4 กลุ่มงานหลัก
- **รายงานเจาะลึกรายหมวด (`#/reports/{module}`):** หน้าแสดงรายละเอียดเฉพาะหมวดงานทั้ง 9 หมวด พร้อมตัวชี้วัดปริมาณงาน แนวโน้มรายวัน การแยกกลุ่มตามข้อมูลอ้างอิง และรายการล่าสุด
- **การควบคุมสิทธิ์ (RBAC):**
  - ผู้ใช้จะมองเห็นและคำนวณยอดเฉพาะหมวดที่มีสิทธิ์ `{module}.view` เท่านั้น
  - การส่งออกไฟล์สรุปภาพรวม (`/api/reports/export`) และรายหมวด (`/api/reports/{module}/export`) จำเป็นต้องมีสิทธิ์ `{module}.export` ต่อหมวดนั้นๆ

---

## 2. วิธีการอ่านตัวเลขและตัวชี้วัด

### 2.1 ช่วงเวลาในการรายงาน
- **ค่าเริ่มต้น (Default):** เมื่อเปิดหน้ารายงาน ระบบจะกำหนดช่วงเวลาของ **เดือนปัจจุบัน** ตั้งแต่วันที่ 1 จนถึงวันปัจจุบัน (เวลาประเทศไทย `Asia/Bangkok`) โดยอัตโนมัติ และนำไปเปรียบเทียบกับวันที่ 1 จนถึงวันเดียวกันของเดือนก่อนหน้า (เช่น 1–15 ต.ค. เทียบกับ 1–15 ก.ย.)
- **เลือกดูรายเดือน (Month Selector):** หากเลือกเดือนย้อนหลัง ระบบจะคำนวณเต็มทั้งเดือน และเปรียบเทียบกับเต็มเดือนก่อนหน้า
- **กำหนดช่วงวันที่เอง (Custom Range):** ระบบจะคำนวณตามช่วงวันที่เลือก และเปรียบเทียบกับช่วงเวลาก่อนหน้าที่มีจำนวนวันเท่ากันอย่างแม่นยำ

### 2.2 กฎการคำนวณตัวเลข
1. **นับตามวันที่ดำเนินงานจริง (`service_date`):** ไม่ขึ้นกับเวลาที่กดบันทึกข้อมูลเข้าสู่ระบบ
2. **ไม่รวมรายการที่ถูกลบ:** ทุกรายการที่มีการลบแบบ Soft Delete (`deleted_at IS NOT NULL`) จะถูกตัดออกจากการคำนวณทั้งหมด
3. **การแยกจำนวนรายการและปริมาณงาน:** จำนวนรายการ (Records) จะไม่ถูกนำไปบวกรวมกับปริมาณงาน (Quantity/Weight/Volume)
4. **ไม่บวกปนหน่วยวัด:** ตัวชี้วัดแต่ละหน่วย (เช่น กิโลเมตร, ตัน, ลูกบาศก์เมตร, บาท, คน, ชุมชน) จะแสดงผลแยกจากกันอย่างชัดเจน ไม่นำค่าที่มีหน่วยหรือความหมายต่างกันมารวมกัน
5. **การเปรียบเทียบเป็นร้อยละ:**
   - สูตรคำนวณ: `((ยอดช่วงปัจจุบัน - ยอดช่วงเปรียบเทียบ) / ยอดช่วงเปรียบเทียบ) * 100`
   - **กรณีช่วงเปรียบเทียบมียอดเป็นศูนย์:** จะแสดงข้อความว่า **"เปรียบเทียบเป็นร้อยละไม่ได้"** (ไม่แสดงค่า infinity หรือหารด้วยศูนย์)

### 2.3 ตัวชี้วัดเฉพาะหมวด
- **งานบำบัดสิ่งปฏิกูล (`septic-treatments`):**
  - ปริมาณกากตะกอน (`sludge_quantity`): รวมยอดทั้งหมดในช่วงเวลา (หน่วย กก.)
  - **ปุ๋ยคงเหลือ (`fertilizer_remaining`):** แสดง **ยอดคงเหลือ ณ ล่าสุด** จากบันทึกสุดท้ายตามวันที่ดำเนินงานในช่วงเวลา พร้อมระบุวันที่อ้างอิง ("ณ วันที่...") โดยไม่นำค่าคงเหลือในแต่ละครั้งมารวมกัน
- **งานโครงการจัดการขยะมูลฝอยและสิ่งแวดล้อม (`waste-management-projects`):**
  - รวมจำนวนชุมชนที่เข้าร่วม (`communities_count`) หน่วยเป็น ชุมชน
  - รวมจำนวนผู้เข้าร่วม (`participants_count`) หน่วยเป็น คน
- **การแยกตามข้อมูลอ้างอิง (Breakdown):**
  - ล้างถนน (`road-washings`): แสดงสถิติจำนวนงานและระยะทางรวมแยกตามเขตรักษาความสะอาด
  - เก็บขนขยะมูลฝอย (`waste-collections`): แสดงสถิติจำนวนงานและน้ำหนักรวมแยกตามประเภทขยะมูลฝอย

## 3. การส่งออกและโครงสร้างไฟล์ CSV

ผู้ใช้ที่มีสิทธิ์ `{module}.export` สามารถดาวน์โหลดรายงานสรุปในรูปแบบ CSV โดยมีมาตรฐานความปลอดภัยและความถูกต้องดังนี้:

### 3.1 คุณสมบัติทางเทคนิค
- **การเข้ารหัสภาษาไทย:** ใช้ UTF-8 พร้อม **BOM (`\xEF\xBB\xBF`)** ทำให้สามารถเปิดอ่านด้วย Microsoft Excel บนระบบปฏิบัติการ Windows ได้อย่างถูกต้อง สระและวรรณยุกต์ไม่ผิดเพี้ยน
- **ความปลอดภัย (CSV Injection Defense):** ช่องข้อมูลที่ขึ้นต้นด้วยอักขระสั่งการคำนวณของโปรแกรมสเปรดชีต เช่น `=`, `+`, `-`, `@` จะถูกครอบด้วยเครื่องหมาย Single Quote (`'`) โดยอัตโนมัติ เพื่อป้องกันการสั่งรันสูตรหรือโค้ดอันตราย

### 3.2 ความหมายของคอลัมน์ใน CSV
| ชื่อคอลัมน์ | คำอธิบาย |
|---|---|
| **ช่วงเริ่ม** | วันที่เริ่มต้นของช่วงรายงาน (`YYYY-MM-DD`) |
| **ช่วงสิ้นสุด** | วันที่สิ้นสุดของช่วงรายงาน (`YYYY-MM-DD`) |
| **หมวดงาน** | รหัสหมวดงานบริการ (เช่น `road-washings`, `septic-treatments`) |
| **จำนวนรายการ** | จำนวนงานที่บันทึกในช่วงรายงาน |
| **จำนวนช่วงเปรียบเทียบ** | จำนวนงานในช่วงเปรียบเทียบ |
| **การเปลี่ยนแปลง (%)** | เปอร์เซ็นต์การเปลี่ยนแปลงเทียบกับช่วงก่อนหน้า (ว่างหากเปรียบเทียบไม่ได้) |
| **ตัวชี้วัด** | ชื่อฟิลด์ตัวชี้วัด (เช่น `distance_km`, `weight`, `fertilizer_remaining`) |
| **ค่า** | ตัวเลขผลรวม หรือค่ายอดคงเหลือล่าสุด |
| **หน่วย** | หน่วยนับ (เช่น กม., ตัน, กก., ลบ.ม., บาท, คน, ชุมชน) |
| **ชนิดค่า** | `sum` (ผลรวมสะสม) หรือ `latest` (ยอดคงเหลือ ณ รายการล่าสุด) |
| **วันที่อ้างอิง** | วันที่ดำเนินงานของรายการล่าสุด (ใช้เฉพาะตัวชี้วัดที่เป็น `latest`) |

## 4. การพิมพ์และบันทึกเป็นเอกสาร PDF

หน้าจอรายงานมีสไตล์ชีตสำหรับการพิมพ์ (`@media print`) รองรับการสั่งพิมพ์ผ่านเบราว์เซอร์ (`Ctrl + P` หรือกดปุ่ม "พิมพ์ / บันทึก PDF"):
- ซ่อนแถบเมนูด้านข้าง (Sidebar), เมนูบน (Header), ปุ่มกด และแบบฟอร์มตัวกรองทั้งหมดโดยอัตโนมัติ
- แสดงเฉพาะหัวข้อรายงาน ข้อมูลสรุป ตัวเลขตัวชี้วัด กราฟแนวโน้ม และตารางสรุป
- ปรับขนาดเอกสารให้พอดีกับหน้ากระดาษ A4 แนวตั้งหรือแนวนอนตามที่ผู้ใช้เลือกในระบบพิมพ์ของเครื่อง
