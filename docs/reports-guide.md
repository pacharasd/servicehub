# คู่มือรายงาน ServiceHub

## หน้ารายงาน

- ภาพรวมแสดงช่วงวันที่ จำนวนงาน และจำนวนหมวดที่มีข้อมูล ตามสิทธิ์ดูของผู้ใช้
- ตารางแยกตาม 4 กลุ่มงาน มีหมวดงาน จำนวนรายการ ตัวชี้วัด ปริมาณ และหน่วย จำนวนรายการแสดงครั้งเดียวต่อหมวดแม้มีหลายตัวชี้วัด
- เปิด “เปรียบเทียบช่วงก่อนหน้า” เพื่อดูจำนวนงานและร้อยละการเปลี่ยนแปลง หากช่วงก่อนหน้าเป็นศูนย์จะไม่คำนวณร้อยละ
- รายหมวดแสดงตารางตัวชี้วัด และแยกตามเขตรักษาความสะอาดหรือประเภทขยะเมื่อมีข้อมูล กด “ดูรายการทั้งหมดในช่วงนี้” เพื่อไปหน้ารายการที่ใช้ช่วงเดียวกัน
- เดือนปัจจุบันนับวันที่ 1 ถึงวันนี้ตามเวลาไทย เดือนย้อนหลังนับเต็มเดือน ช่วงกำหนดเองรวมวันเริ่มและวันสิ้นสุด
- จอแคบเลื่อนได้เฉพาะกรอบตาราง ซึ่งเลือกด้วยคีย์บอร์ดได้

## ดาวน์โหลด Excel

“ดาวน์โหลด Excel” สร้างไฟล์ .xlsx ประกอบด้วยชีตสรุปและชีตรายการจริงแยกตามหมวด ไม่จำกัดเฉพาะหน้าที่กำลังดู สูงสุด 5,000 รายการรวมทุกหมวดต่อครั้ง หากเกินต้องเลือกช่วงแคบลง ระบบไม่ตัดรายการออกเอง

- ชื่อรายงาน ชื่อหมวด หัวคอลัมน์ และหน่วยเป็นภาษาไทยเต็ม
- ชีตสรุปมีช่วงวันที่ เวลาสร้างตามเวลาไทย และจำนวนงานพร้อมตัวชี้วัด ยอดสรุปคำนวณจากรายการที่ส่งออกชุดเดียวกัน
- ชีตรายการเรียงตามวันที่ดำเนินงานล่าสุดแล้วตาม ID ใช้ชื่อเขต/ประเภทแทน ID และเก็บรหัสเป็นข้อความเพื่อรักษาศูนย์นำหน้า
- วันที่แสดงวัน/เดือน/ปี พ.ศ. ตัวเลขเป็นตัวเลขจริงและมีทศนิยมสูงสุด 3 ตำแหน่ง ข้อความผู้ใช้เป็นเซลล์ข้อความเพื่อไม่ให้ทำงานเป็นสูตร
- ตรึงหัวตาราง เปิดตัวกรอง และขึ้นบรรทัดสำหรับข้อความยาว
- ส่งออกเฉพาะหมวดที่มีสิทธิ์ export จึงอาจมีข้อมูลน้อยกว่าหน้าจอที่ใช้สิทธิ์ view บันทึก Audit Log ทุกครั้งที่สร้างไฟล์สำเร็จ

API ส่งออกเดิมรับ `format=xlsx` เพิ่มเติม ค่าเริ่มต้นยังเป็น CSV; CSV สรุปอยู่ใน “ตัวเลือกไฟล์อื่น” และรักษาหัว/รูปแบบเดิม CSV รายการดิบไม่เปลี่ยน

## ความหมายของตัวเลข

ไม่นับรายการ soft delete งานมูลฝอยและงานคลองนับตามวันเริ่มครั้งเดียว แม้งานคร่อมเดือน ไม่กระจายยอดตามจำนวนวัน น้ำหนักมูลฝอยเป็นกิโลกรัม ระยะทางงานคลองและงานลอกท่อเป็นเมตรแม้ชื่อฟิลด์เป็น distance_km หมวดระยะทางอื่นเป็นกิโลเมตร ปริมาณงานคลองเป็นลูกบาศก์เมตร ไม่รวมค่าต่างหน่วยหรือความหมาย

ปุ๋ยคงเหลือแสดงค่าล่าสุดตามวันดำเนินงานแล้วตาม ID พร้อมวันที่อ้างอิง ไม่รวมคงเหลือทุกครั้งเข้าด้วยกัน หากไม่มีงานแสดง — ส่วนผลรวมแสดง 0

## พิมพ์ / บันทึก PDF

ใช้ปุ่ม “พิมพ์ / บันทึก PDF” ของเบราว์เซอร์ พิมพ์เฉพาะสรุป A4 แนวนอน ซ่อนเมนู ตัวกรอง ปุ่ม และส่วนเปรียบเทียบ หัวตารางซ้ำในหน้าถัดไปและไม่ตัดกลางแถว รายการจริงทั้งหมดอ่านจาก Excel แทน

## ติดตั้งและนำใช้

- Dependency: PhpSpreadsheet ตาม composer.lock; PHP 8.2 ขึ้นไป พร้อม gd, zip และ extensions ที่ Composer กำหนด
- XAMPP เปิด extension=gd และ extension=zip ใน php.ini แล้ว restart Apache เพื่อให้ PHP ฝั่งเว็บโหลดการตั้งค่าใหม่ ตรวจ CLI ด้วย php -m และ composer check-platform-reqs
- Plesk ตรวจ PHP ทั้ง CLI และ handler ของโดเมนให้ตรงกับข้อกำหนด ห้ามใช้ --ignore-platform-reqs ใช้ composer install --no-dev --prefer-dist --optimize-autoloader จาก lock เดียวกับรุ่นที่ทดสอบ
- ส่งโค้ด resources/report-catalog.json, dependency และ public/dist รุ่นเดียวกัน ไม่ต้อง migrate ฐานข้อมูล
- ไฟล์ชั่วคราวสร้างใน storage/app/private/report-exports และลบทิ้งหลังส่ง ตรวจให้เว็บเขียนโฟลเดอร์นี้ได้ และไม่เปิดจาก document root
- ก่อน deploy รัน PHPUnit, JavaScript tests, node --check, Pint และ build หลัง deploy ตรวจ HTTP ของ asset/API/ดาวน์โหลด XLSX และ log หากผิดพลาดย้อนกลับโค้ด lock/dependency และ asset รุ่นก่อน ไม่มีการเปลี่ยน schema
- ยังไม่มีช่องทาง CLI Plesk ที่เชื่อมต่อในงานนี้ การตรวจ production ต้องทำเมื่อมีช่องทางเข้าเซิร์ฟเวอร์และได้รับคำขอ deploy

## การ์ดงานบริการมูลฝอยบนแดชบอร์ด

แสดงจำนวนงาน น้ำหนักรวม น้ำหนักขยะอันตรายเฉพาะรหัส WASTE-004 (ไม่รวม 2.2.2) และประเภทที่มีน้ำหนักมากที่สุดในช่วงวันเริ่มเดียวกัน หากน้ำหนักเท่ากันเรียงรหัสจากน้อยไปมาก ไม่รวมรายการลบ แต่รวมประเภทระงับที่มีงานอ้างอิง การ์ดไม่มีลิงก์รายงาน
