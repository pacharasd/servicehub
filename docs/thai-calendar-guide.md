# การใช้ปฏิทินภาษาไทย

ช่องวันที่ในฟอร์มงานบริการ ตัวกรอง แดชบอร์ด รายงาน และประวัติการแก้ไขแสดงปี พ.ศ. ด้วยเลขอารบิก

- พิมพ์วัน/เดือน/ปี พ.ศ. เช่น `09/10/2569` หรือกดปุ่มปฏิทินเพื่อเลือกวัน
- ช่องเดือนในรายงานพิมพ์ `10/2569` หรือเลือกเดือนภาษาไทยกับปี พ.ศ.
- ปุ่ม “วันนี้” ใช้วันที่ประเทศไทย ปุ่ม “ล้างค่า” ทำให้ช่องว่าง; ช่องบังคับต้องเลือกใหม่ก่อนส่งฟอร์ม
- เปลี่ยนเดือนหรือปีจากตัวเลือกด้านบน ใช้ลูกศรบนแป้นพิมพ์เลื่อนวัน, Home/End ไปต้น/ท้ายสัปดาห์, PageUp/PageDown เปลี่ยนเดือน และ Shift ร่วมกับ PageUp/PageDown เปลี่ยนปี
- Enter เลือกวัน Escape ปิดปฏิทินและคืนตำแหน่งไปช่องวันที่ เปิดปฏิทินด้วยปุ่มหรือ Alt+ลูกศรลง
- วันที่ที่ไม่มีจริง เช่น `31/04/2569` จะถูกแจ้งข้อผิดพลาด ไม่ถูกปรับเป็นวันอื่น

วันที่ที่ API และฐานข้อมูลใช้ยังเป็น ค.ศ. รูปแบบ `YYYY-MM-DD` เช่น `2026-10-09` และเดือนเป็น `YYYY-MM` ไม่ต้องแก้ข้อมูลเดิมหรือโครงฐาน

การทดสอบอัตโนมัติใช้ Node/DOM จำลองและ HTTP/CLI ไม่ได้ยืนยันการแสดงผลจริงบนมือถือหรือโปรแกรมอ่านหน้าจอ ต้องตรวจจากการใช้งานจริงเพิ่มเติม
