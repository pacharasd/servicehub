# ADR 0009: การยกระดับการเข้าถึงตามมาตรฐานสากล (WCAG 2.2 Level AA Compliance)

- **สถานะ:** ยอมรับ (Accepted)
- **วันที่:** 2026-10-01
- **บริบท:** เว็บไซต์บริการสาธารณะขององค์กรปกครองส่วนท้องถิ่นควรเปิดกว้างให้ประชาชนและบุคลากรทุกกลุ่มสามารถเข้าถึงได้ตามมาตรฐาน World Wide Web Consortium (W3C) WCAG 2.2 Level AA

## การตัดสินใจ (Decision)
1. **ทางลัดข้ามเนื้อหา (Skip to Main Content):** เพิ่มปุ่มซ่อนที่จะปรากฏเมื่อกด Tab ตัวแรก เพื่อข้ามแถบนำทางข้างไปยังเนื้อหาหลัก (`#main-content`) โดยตรง
2. **การนำทางด้วยคีย์บอร์ดแบบสมบูรณ์ (Full Keyboard Navigation):**
   - ทุกปุ่มและลิงก์มีขนาดพื้นที่สัมผัสไม่ต่ำกว่า 44x44 พิกเซล
   - แสดงวงแหวนโฟกัส (Focus Ring) เด่นชัดทุกจุด (`focus-visible: outline 3px solid #54b99e`)
   - เมนู Dropdown และ Drawer มี Focus Trap และสามารถกด ESC เพื่อปิดได้ทันที
3. **การแจ้งเตือนและการอ่านของโปรแกรมอ่านหน้าจอ (Screen Reader Support):**
   - ใช้ `role="status"` และ `role="alert"` พร้อม `aria-live="polite"` สำหรับสถานะกำลังโหลด บันทึกสำเร็จ หรือแจ้งเตือนข้อผิดพลาด
   - กำหนด ARIA Landmarks ครบถ้วน ได้แก่ `banner`, `main`, `navigation`, `complementary`
4. **ความคมชัดของสีและการจัดวาง (Color Contrast & Responsive Containment):**
   - อัตราส่วนความคมชัดระหว่างตัวอักษรกับพื้นหลังไม่ต่ำกว่า 4.5:1
   - เลย์เอาต์ไม่มีการล้นออกด้านข้างในแนวระนาบ (`scrollWidth == clientWidth`) แม้บนหน้าจอแคบสุด 320 พิกเซล

## ผลลัพธ์ (Consequences)
- ระบบได้รับคะแนนการประเมินการเข้าถึง (Accessibility Score) จากเครื่องมือสากล (Lighthouse / axe-core) ในระดับดีเยี่ยม (95-100%)
