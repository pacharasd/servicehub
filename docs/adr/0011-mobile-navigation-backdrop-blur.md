# ADR 0011: ฉากหลังเบลอแบบกระจกฝ้าและการควบคุมการแสดงผลเมนูมือถือ (Mobile Drawer Backdrop Blur & Glassmorphism)

## สถานะ (Status)
ยอมรับแล้ว (Accepted) — 2026-10-02

## บริบท (Context)
ในการใช้งานบนอุปกรณ์ขนาดหน้าจอมือถือและแท็บเล็ต (< 1024px) เมื่อผู้ใช้กดปุ่มแฮมเบอร์เกอร์เพื่อเปิดเมนูแถบข้าง (Mobile Sidebar Drawer):
- เดิมฉากหลัง (`#mobile-backdrop`) ใช้เพียงการสลับคลาส `hidden` กับสีทึบพื้นฐาน `bg-slate-950/35` ปรากฏขึ้นมาอย่างฉับพลันโดยไม่มีเอฟเฟกต์เฟด
- ขาดความลึกและมิติทางสายตา (Visual Hierarchy) ทำให้ไม่สามารถตัดโฟกัสเนื้อหาในหน้าหลักได้อย่างชัดเจน
- ต้องการปรับปรุงประสบการณ์การใช้งานให้เป็นไปตามมาตรฐานสากล ทั้งด้านความสวยงาม (Glassmorphism), ความนุ่มนวลของแอนิเมชัน, และการเข้าถึง (Accessibility - WCAG 2.2 AA)

## การตัดสินใจ (Decision)
เราตัดสินใจนำเอฟเฟกต์ **Backdrop Blur ระดับมาตรฐาน (4px - 8px)** ผสานกับโครงสร้าง Transition ที่ได้มาตรฐานมาใช้งาน:

1. **เอฟเฟกต์ฉากหลังแบบ Glassmorphism:**
   - ใช้ CSS `backdrop-filter: blur(4px)` ผ่าน Tailwind class `backdrop-blur-sm` ร่วมกับเฉดสีพื้นหลังกึ่งโปร่งแสง `bg-slate-950/40`
   - ช่วยเบลอเนื้อหาด้านหลัง (App Content & Topbar) อย่างนุ่มนวล พร้อมคงคอนทราสต์ของแถบเมนูข้าง (Sidebar) ไว้อย่างคมชัด

2. **แอนิเมชันและ Transition ที่ราบรื่น:**
   - เปลี่ยนจากการสลับคลาส `hidden` เป็นการคง Element ไว้ใน DOM แล้วควบคุมความโปร่งใสผ่าน `opacity-0` / `opacity-100`, `pointer-events-none` / `pointer-events-auto`, และ `invisible` / `visible`
   - มีระยะเวลาการเฟด `duration-300` ที่สอดคล้องกับการเลื่อนเข้าออกของ Sidebar (`duration-200`)

3. **มาตรฐานการเข้าถึง (WCAG 2.2 AA & Motion Accessibility):**
   - รองรับ `motion-reduce:transition-none` เพื่อปิดแอนิเมชันทันทีเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหวในระบบปฏิบัติการ (`prefers-reduced-motion: reduce`)
   - กำหนด CSS Fallback ผ่าน `@supports not (backdrop-filter: blur(4px))` โดยเพิ่มความเข้มของสีพื้นหลังเป็น `rgba(15, 23, 42, 0.75)` สำหรับเบราว์เซอร์ที่ไม่รองรับ Backdrop Filter
   - ล็อกการเลื่อนหน้าจอหลัก (`body.style.overflow = 'hidden'`) ขณะเมนูเปิด และเปิดให้คลิกฉากหลังหรือกดปุ่ม `Escape` เพื่อปิดเมนูได้โดยอัตโนมัติ

## ผลที่ตามมา (Consequences)
- **ข้อดี:** มิติการมองเห็นและการใช้งานบนอุปกรณ์พกพาสะอาด ทันสมัย และสบายตายิ่งขึ้น สอดคล้องกับแนวทางสากลสมัยใหม่และมาตรฐาน Accessibility
- **สิ่งที่ต้องระวัง:** ประสิทธิภาพการเรนเดอร์กราฟิกบนอุปกรณ์รุ่นเก่า — ได้รับการบรรเทาโดยใช้ระดับเบลอ `blur-sm` (4px) ที่ใช้พลังประมวลผล GPU ต่ำ และมี fallback ปลอดภัย
