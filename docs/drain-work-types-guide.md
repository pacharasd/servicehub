# ประเภทงานลอกท่อและหน่วยเมตร

## การใช้งาน

เปิดเมนู งานบริหารจัดการสิ่งปฏิกูล → งานลอกท่อระบายน้ำ → ประเภทงานลอกท่อ แล้วเพิ่มรหัสและชื่อประเภทที่หน่วยงานใช้จริง ไม่มีประเภทตั้งต้นที่ระบบสมมติให้ รหัสไม่เกิน 50 และชื่อไม่เกิน 255 ตัวอักษร โดยรหัสและชื่อต้องไม่ซ้ำ

ฟอร์มเพิ่ม/แก้ไขงานต้องเลือกประเภทงาน ข้อมูลเก่าแสดง “ยังไม่ระบุประเภทงาน” จนกว่าจะเลือกเมื่อบันทึกแก้ไข หากไม่มีประเภทที่เลือกได้ให้เพิ่มก่อน หรือติดต่อผู้มีสิทธิ์จัดการประเภท รายการที่ใช้ประเภทซึ่งระงับแล้วคงประเภทเดิมได้ แต่ไม่สามารถเลือกประเภทระงับไปใช้กับงานอื่นใหม่ได้

หน้าประเภทแสดงจำนวนงานที่ยังไม่ลบ ห้ามลบประเภทที่มีงานอ้างอิงแม้งานถูก soft delete แล้ว ให้แก้ไขเป็นระงับใช้งานแทน

ระยะทางงานลอกท่อใช้เมตรทั้งหมด เช่น 100 แสดง 100 เมตร, 3.80 แสดง 3.8 เมตร ไม่แปลงตัวเลขเดิม API/ฐาน/หัว CSV ยังคงชื่อ `distance_km` เพื่อความเข้ากันได้ ปริมาณตะกอนยังใช้ลูกบาศก์เมตร Excel แสดงชื่อและรหัสประเภทในคอลัมน์แยก

## นำใช้ (ยังไม่รันกับฐานใช้งานในงานนี้)

1. สำรองฐานข้อมูลและเก็บโค้ด/API/asset รุ่นก่อนหน้า ปิดการบันทึกชั่วคราวระหว่างอัปเดต
2. ส่ง migration ใหม่และโค้ดรุ่นเดียวกันขึ้นเซิร์ฟเวอร์ รันด้วย PHP ของเว็บไซต์:

```powershell
php artisan migrate --force
php artisan servicehub:install-drain-work-types
```

3. คำสั่งสิทธิ์เพิ่มเฉพาะ `drain-work-types.*`: admin/super-admin ครบ, staff ดู/เพิ่ม/แก้ไข, viewer/auditor ดู โดยไม่ sync หรือลบสิทธิ์เดิม ผู้ใช้บทบาทกำหนดเองให้ผู้ดูแลมอบสิทธิ์ตามงาน อย่ารัน `ReferenceDataSeeder` หรือคำสั่ง sync สิทธิ์รวมเพื่ออัปเดตฐานใช้งาน
4. อัปเดต API และ `public/dist` พร้อมกัน ตรวจรายการเก่าและระยะทางเดิม จากนั้นเพิ่มประเภทจริงอย่างน้อยหนึ่งประเภท ทดสอบบันทึก ค้นหา และดาวน์โหลดไฟล์ก่อนเปิดให้ใช้งาน

เพิ่มตาราง `drain_work_types` และ foreign key nullable `drain_cleanings.drain_work_type_id` เท่านั้น ไม่เปลี่ยนระยะทาง/ปริมาณเดิม ไม่เติมประเภทลงข้อมูลเก่า การย้อน migration จะลบข้อมูลประเภท จึงต้องสำรองและเก็บข้อมูลที่เพิ่มหลังอัปเดตก่อนย้อนฐาน

API ข้อมูลพื้นฐานใช้ `/api/references/drain-work-types` และ API งานใช้ URL เดิม เพิ่มฟิลด์บังคับ `drain_work_type_id` ผลตอบกลับมีชื่อ `drain_work_type` และรหัส `drain_work_type_code` สำหรับรายการที่มีประเภท
